# Project credits and lineage

## Original project

**Last Train was created by COUnT (count-rzy).** The original project and its development history are available in the [upstream GitHub repository](https://github.com/count-rzy/diamondtime-train).

**Special thanks to Sonya (Ryuko)** for her contributions, guidance, patience and programming mentorship, and for helping the creator grow as a developer. Her support is part of the story behind Last Train.

The Linux fork is based on that project. Its purpose is to make the application usable from Linux through source installation and a shell command interface. The original project remains upstream; this fork is intended for Linux computers.

## Artwork, fonts and software

The project’s pixel-art direction and source asset workflow are documented in [ART_DIRECTION.md](../front/art/ART_DIRECTION.md). Font license notices are kept in [`docs/licenses/`](licenses/).

The application incorporates React, Vite, Django, Django REST Framework, Waitress and other open-source packages. Their own license and notice files remain with the source or installed dependencies. Refer to each project’s license for its terms.
